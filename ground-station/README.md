# Ground Station

로켓 비행 데이터를 수신하고 실시간으로 모니터링하는 지상국(Ground Station) 소프트웨어 디렉터리입니다.

## 📡 주요 기능
- 실시간 텔레메트리(고도, 상태, 전압, GPS 등) 패킷 파싱 및 모니터링 UI
- 지상 점검 및 모드 전환 업링크 명령 송신
- 수신 데이터 실시간 파일 저장(로그)
