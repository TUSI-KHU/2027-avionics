# 📝 회의록 원시 기록 (Raw Meetings)

> [!NOTE]
> 본 디렉터리는 팀 정기/비정기 회의에서 발생한 날것의 회의록(Raw notes)을 보관하는 공간입니다.
> Karpathy LLM Wiki 규칙에 따라, 원본 회의록은 수정하지 않는 불변 기록으로 보존되며, LLM 에이전트가 이를 읽어 [[docs/wiki/|Living Wiki]]로 지식을 컴파일합니다.

## ✍️ 회의록 작성 요령
1. [[docs/templates/template-raw-meeting|docs/templates/template-raw-meeting.md]] 서식을 복사하여 `YYYY-MM-DD-<주제>.md` 형태로 저장합니다.
2. 회의 안건, 논의 내용, 주요 결정 사항, Action Items를 자유롭게 작성합니다.
3. 회의가 끝나면 AI 에이전트에게 "회의록 내용을 Living Wiki에 반영해줘"라고 요청하면 [[docs/WIKI_PROTOCOL|컴파일 파이프라인]]에 따라 위키가 자동 업데이트됩니다.
